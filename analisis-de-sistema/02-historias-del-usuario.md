# 02 — Historias de usuario

Formato: **Como [actor], quiero [acción], para [beneficio].**

## Historias base (guía)

| ID | Actor | Historia de usuario |
|---|---|---|
| HU01 | Cliente | Como cliente, quiero buscar y consultar productos, para encontrar el producto que necesito. |
| HU02 | Seller | Como seller, quiero registrar y gestionar mis productos, para ofrecerlos a los clientes. |
| HU03 | Cliente | Como cliente, quiero gestionar los productos de mi carrito, para preparar los productos que deseo comprar. |
| HU04 | Cliente | Como cliente, quiero realizar un pedido con los productos de mi carrito, para completar mi compra. |
| HU05 | Administrador | Como administrador, quiero gestionar los sellers de la plataforma, para administrar a los vendedores registrados. |
| HU06 | Cliente | Como cliente, quiero consultar mis pedidos y su estado, para conocer el estado de mis compras. |

## Historias complementarias

| ID | Actor | Historia de usuario |
|---|---|---|
| HU07 | Cliente | Como cliente, quiero registrarme e iniciar sesión, para realizar compras y guardar mis datos de forma segura. |
| HU08 | Cliente | Como cliente, quiero pagar mi pedido en línea, para completar la compra sin salir de la plataforma. |
| HU09 | Cliente | Como cliente, quiero registrar mis direcciones de entrega, para recibir mis pedidos en el lugar indicado. |
| HU10 | Cliente | Como cliente, quiero recibir mi comprobante de pago electrónico, para tener constancia legal de mi compra. |
| HU11 | Seller | Como seller, quiero consultar los pedidos que incluyen mis productos, para preparar y despachar mis ventas. |
| HU12 | Seller | Como seller, quiero actualizar el stock de mis productos, para no vender productos que no tengo disponibles. |
| HU13 | Administrador | Como administrador, quiero gestionar las categorías de productos (alimento, accesorios, higiene, salud), para mantener el catálogo organizado. |
| HU14 | Cliente | Como cliente, quiero filtrar productos por tipo de mascota, marca y precio, para encontrar más rápido lo que busco. |
