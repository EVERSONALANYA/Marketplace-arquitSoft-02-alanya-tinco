# Marketplace de productos para mascotas

## Nombre
Everson Alanya Tinco — Código 27220504

## Descripción
Marketplace académico de productos para mascotas, donde diferentes sellers ofrecen sus productos (alimento, accesorios, higiene, salud) y los clientes pueden buscarlos, agregarlos al carrito, realizar pedidos y pagarlos en línea.

## Caso de estudio
GoPet (https://www.gopet.pe/) como referencia funcional.

## Curso
Arquitectura de Software (IS-488) — UNSCH
Docente: Ing. Lizbeth Jaico Quispe — Semestre 2026-II
